# Contributing

Stipra values reproducible art direction, exact physical-plate alignment, and transparent licensing. Please open an issue with a small reproducer, original/reference screenshots only if you have rights to share them, the seed and recipe, expected behavior and actual behavior.

PRs should refer to an issue, use a focused branch, include tests and any reference-vs-render diagnostics. For SVG and raster export changes, verify the same geometry and ink masks at matching dimensions. Avoid adding hosted API dependencies.

See [AGENTS.md](AGENTS.md) for the complete issue/PR workflow.
