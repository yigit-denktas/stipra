# Isolated Skia Canvas comparison

Manual research harness for #14. This is outside the application and published lean packages. It does not upgrade Stipra, change goldens, authorize native redistribution or establish physical print quality.

The source snapshot is pinned to `24f731fb93a0aaee0f049a7ca0bb59f7215bcfb2`. Each case group runs in a fresh Node process, with every `skia-canvas` import redirected to exactly one isolated prefix. JavaScript dependencies are shared from the source checkout; run its locked installation first. Workers reject a loaded native addon outside their selected prefix. No owner photographs are read.

## Reproduce on Linux x64 glibc

Use Node 24.19.0, npm 11.9.0 and Python 3.12.14 for the recorded environment. Poppler `pdftoppm` must be on PATH. Prepare the source checkout's dependencies and pinned OFL fonts using `npm ci` and `npm run prepare:fonts`. The existing 3.0.8 Linux binary must match the recorded SHA-256; the harness copies that reviewed binary after checking it. It never compiles or downloads a substitute binary.

Create an external Python environment and install `requirements.txt` there. These analysis tools are not application dependencies. With that Python executable:

```sh
python scripts/experiments/skia-compare/prepare.py /absolute/new-experiment /absolute/stipra-checkout
python scripts/experiments/skia-compare/run.py /absolute/new-experiment
```

The experiment directory must be new and outside the checkout. `prepare.py` installs both exact backend lockfiles with lifecycle scripts disabled. v4 uses its pinned npm platform package. The fixture generator checks every generated byte against `pins.json`; a mismatch fails instead of regenerating a baseline. Pillow's codec versions can affect generated JPEG/WebP bytes, so use the recorded toolchain. No native binary, font or npm payload belongs in a commit or review archive.

`run.py` refuses an existing result directory. It runs decode, masks, fonts, reports and paper cases, then three alternating fresh-process memory trials per version. Missing-payload behavior is tested in additional isolated copies. `analyze.py` compares canonical RGBA, encoded streams, geometry, text placements, embedded font streams, recipes, Poppler-rendered pages, QR decoding and reference checks. An exclusive analysis lock prevents concurrent writes to the same review output.

## Reading the result

- `results/comparison.json`: measurements and explicit promotion stops. `stop-and-review` is an expected experiment verdict, not a harness execution failure.
- `results/v3/` and `results/v4/`: raw worker records, canonical RGBA, images and synthetic packages/reports.
- `inputs/manifest.json`: frozen input identities. EXIF variants share the same JPEG scan data.
- `controls/`: frozen v3 paper bitmaps used on both backends to isolate report texture differences.
- `review/`: 150-DPI page renders; comparison also uses 300 DPI.
- `environment.json`: generator/runtime information from preparation. Record the host, Poppler version and resource constraints alongside benchmark evidence.

Results-v2 blocks PDF attachment changes except verified encoded-image hash leaves. Those exceptions require actual paired PNG hashes and equal decoded pixels. Package print contracts, package image pixels/identities and PDF links also block on changes. This research check does not alter the application's licensing release gate. Future environment records are automatically observed by preparation; replay acceptance remains unset until separately established.

Run the standard-library contract tests and the real-PDF attachment mutation check:

```sh
python -m unittest discover -s scripts/experiments/skia-compare -p 'test_*.py' -v
python scripts/experiments/skia-compare/verify-corrections.py /absolute/existing-experiment
```

The second command uses the declared analysis dependencies and existing synthetic reports. It creates only temporary mutated copies, asserts unchanged page drawing streams and rejects altered recipes/DPI/layout/hash metadata. Historical source evidence and archives remain unchanged; the public diagnostic copy redacts host paths.

Memory samples use one 1024×768 canvas, five warmup and 60 recorded PNG exports, incremental marks and explicit GC after each encode. Cycle timings include that GC. Three short CPU trials cannot establish leak freedom, long-run stability, GPU behavior or a general performance advantage.

Existing production goldens are read-only. Pixel, geometry, alpha, color, text metrics or QR changes require review. Encoded-byte-only differences are recorded separately. Promotion and native notice clearance remain separate decisions. See [the measured result](../../../docs/SKIA-V4-EXPERIMENT.md).
