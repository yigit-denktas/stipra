# Reconstruction Study 01 (research only)

From a trusted repository checkout, use its existing Node dependencies and a separate Python environment with NumPy, SciPy and Pillow. The recorded environment is in `docs/evidence/reconstruction-study-01.json`. Keep optional VTracer outside the product dependencies:

```sh
mkdir -p out/reconstruction-study/sources
curl --fail --location https://raw.githubusercontent.com/scikit-image/scikit-image/v0.21.0/skimage/data/astronaut.png -o out/reconstruction-study/sources/astronaut.png
curl --fail --location https://upload.wikimedia.org/wikipedia/commons/2/27/Capitol_Building_Full_View.jpg -o out/reconstruction-study/sources/capitol.jpg
python -m pip install --target out/reconstruction-python --no-deps vtracer==0.6.15
python examples/reconstruction-study/study.py
node examples/reconstruction-study/render.cjs
python examples/reconstruction-study/replay.py
python examples/reconstruction-study/measure.py
npm run prepare:fonts
python examples/reconstruction-study/report.py
python examples/reconstruction-study/measure.py
python examples/reconstruction-study/package.py
```

Report generation additionally uses ReportLab. The script rejects downloaded sources whose SHA-256 differs from the committed evidence; upstream URLs can change. Do not substitute an image and silently update its expected hash. Study resampling is explicit and separate from production's native-frame contract.

The output directory contains source-normalized PNGs, six same-frame comparisons, native SVGs where geometry exists, an existing Stiprā baseline with normalized recipe, measured hashes/parameters, two contact sheets and a three-page A3 landscape PDF (two visual pages plus measured budgets). Reruns overwrite only this named research output directory. No source photographs or native packages are committed or bundled into the core.

`study.py` is an original bounded numerical experiment, not a new plotting library. Its continuous route is greedy, not optimized TSP; the dither is Pillow's existing implementation; contours are generated by VTracer. See `docs/RECONSTRUCTION-STUDY-01.md` for source rights, conclusions and limits.

## Revision v2 controls

Four black/white mark methods are calibrated by measured decoded coverage (18 bisection steps) to within 0.5 percentage point of the same Pillow L darkness target. Stipple radius starts from local cell ink area; hatch width starts from local tone × grid-cell area / segment length. Final calibration accounts for overlap and edge clipping. Hybrid uses the actual directional hatch and stipple elements. Coverage is matched; vector complexity is deliberately reported rather than falsely equated. The metric is a global mean control, not a local tone guarantee: the evidence records 16 × 16 signed block-error quantiles, per-decile signed error and 32-bin tone histograms for every method, plus circle-radius/stroke-width and overlap/clipping statistics. Dither is an unconstrained raster reference. VTracer is not coverage-scaled: its exact four palette fills and nearest-band histogram are verified, and per-band IoU / pixel band agreement / boundary mismatch are recorded so preserved band counts cannot hide lost spatial structure. Runtime is split into calibration and final-raster milliseconds; baseline engine time is recorded separately.

Points are frozen in `examples/reconstruction-study/points/`; do not silently resample or replace them. `measure.py` writes the one canonical `docs/evidence/reconstruction-study-01.json`. Run it before the PDF for tables and after the PDF for final artifact hashes. Runtime fields vary, while decoded-pixel hashes distinguish encoder changes from changed artwork. `replay.py` snapshots the generated artifacts, re-runs both generators and writes `replay-check.json` for 32 same-environment SVG/decoded-pixel identities; `measure.py` records the result, and the PDF states it. `package.py` validates every evidence hash and writes a non-recursive full-archive manifest with POSIX member names. It requires a trusted complete repository checkout for replay; the study archive is evidence, not a self-contained Stiprā distribution. The committed canonical evidence predates the review-branch fields, so regenerate it on the recording environment before quoting local-tone, spatial, split-timing or generation-commit values. Study text artifacts use explicit UTF-8/LF writes; `.gitattributes` holds the study tree (and its evidence/tests) to LF on Windows checkouts.

The single-ink reference uses an authored Pillow-L darkness mask through the existing engine in solid mode; it is not an automatic production halftone. The green/coral v1 baseline is retained as context only. Core production API, dependencies and defaults are unchanged. Exact package/crate VTracer versions and all flags are in canonical evidence. Real blind human rankings and physical tests remain open.
