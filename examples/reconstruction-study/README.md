# Reconstruction Study 01 (research only)

From a trusted repository checkout, use its existing Node dependencies and a separate Python environment with NumPy, SciPy and Pillow. The recorded environment is in `docs/evidence/reconstruction-study-01.json`. Keep optional VTracer outside the product dependencies:

```sh
mkdir -p out/reconstruction-study/sources
curl --fail --location https://raw.githubusercontent.com/scikit-image/scikit-image/v0.21.0/skimage/data/astronaut.png -o out/reconstruction-study/sources/astronaut.png
curl --fail --location https://upload.wikimedia.org/wikipedia/commons/2/27/Capitol_Building_Full_View.jpg -o out/reconstruction-study/sources/capitol.jpg
python -m pip install --target out/reconstruction-python --no-deps vtracer==0.6.15
python examples/reconstruction-study/study.py
node examples/reconstruction-study/render.cjs
npm run prepare:fonts
python examples/reconstruction-study/report.py
```

Report generation additionally uses ReportLab. The script rejects downloaded sources whose SHA-256 differs from the committed evidence; upstream URLs can change. Do not substitute an image and silently update its expected hash. Study resampling is explicit and separate from production's native-frame contract.

The output directory contains source-normalized PNGs, six same-frame comparisons, native SVGs where geometry exists, an existing Stiprā baseline with normalized recipe, measured hashes/parameters, two contact sheets and a two-page A3 landscape PDF. Reruns overwrite only this named research output directory. No source photographs or native packages are committed or bundled into the core.

`study.py` is an original bounded numerical experiment, not a new plotting library. Its continuous route is greedy, not optimized TSP; the dither is Pillow's existing implementation; contours are generated by VTracer. See `docs/RECONSTRUCTION-STUDY-01.md` for source rights, conclusions and limits.
